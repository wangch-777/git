# 任务 02：改善实验质量（去重敏感性分析 + 仅验证集选参）

> 执行方：Codex（机器学习 / 数据 / Worker / 后端职责）。
> 前端（TraeWorkCN）不参与本任务，请勿改动 `frontend/` 下任何文件。

## 目标

在“训练/验证/测试”协议内降低正常流量误报率，并堵住“反复调测试集刷分”的隐患。核心产出是一份**可复现**的去重敏感性分析，以及一次**只在验证集上**完成的参数/阈值选择实验。

## 现状与已知事实（请直接采信，无需重新探查）

来自 `docs/baseline-results.md` 与 `ml/cli.py baseline()`：

- 数据：`data/raw/UNSW_NB15_training-set.csv`（175,341 条）、`UNSW_NB15_testing-set.csv`（82,332 条），各 45 列。
- 特征：删去 id/label/attack_cat 后 42 个特征（39 数值 + 3 类别），协议见 `configs/feature_schema.json`。
- 划分：`GroupShuffleSplit` 按特征行哈希分组，seed=42，验证 20%，训练/验证组无重叠；训练 140,145 条、验证 35,196 条。
- 重复：原训练文件**74,301 条重复特征记录**；原测试文件有**8,541 条特征记录也出现在训练文件**中。
- 基线模型：RandomForest（n_estimators=80、max_depth=18、min_samples_leaf=2、class_weight=balanced、random_state=42、n_jobs=2），二分类阈值固定 0.5，攻击为正类。
- 基线指标：验证 FPR **4.94%**、测试 FPR **16.07%**；验证 Recall 94.60%、测试 Recall 96.77%。完整表见 `artifacts/baseline/summary.json`、`data_quality.json`、`evaluation.json`。

## 任务步骤（按顺序执行）

### 1. 去重敏感性分析

- 实验 A（对照）：保持现状，不去重。可直接复用已有 `artifacts/baseline/summary.json`，不必重复训练，但需在报告里注明复用了基线结果。
- 实验 B（训练侧去重）：对原训练文件按 42 个特征做行哈希去重（保留首次出现，`keep='first'`），之后沿用同样的 GroupShuffleSplit 划分与同样的模型/参数/seed 训练。**测试集不做任何修改**。对比验证/测试的 precision/recall/f1/fpr/accuracy。
- 实验 C（诊断，非最终评价）：额外报告“去掉测试集中与训练集重复的特征行后”的指标，作为无泄漏泛化的上界估计；明确指出这只用于诊断重复记录的影响，不作为最终成绩，也不参与参数选择。

每组记录：训练样本数、去重条数、验证/测试的六项指标。

### 2. 明确数据划分规则（写入报告，作为约束固化）

- 训练 / 验证 / 测试三者严格隔离；去重只作用于训练侧；测试集保持原样用于最终评估。
- 预处理只在训练部分拟合（现有 `ml/` 已实现，确认不越界即可）。

### 3. 仅在验证集上选参数与阈值

- 参数搜索（如 max_depth、min_samples_leaf、n_estimators）以验证集 F1 或 PR-AUC 为选择依据；**禁止**用测试集指标挑选。
- 阈值：基于验证集概率画 Precision-Recall 曲线（或 Recall-FPR 曲线），在满足“召回率 ≥ 目标值（建议 ≥ 0.90，可自行论证）”约束下选 FPR 最小的阈值，固定后再在测试集上评估**一次**。

### 4. 降误报尝试（可选但推荐至少做一项）

对比 `class_weight=balanced` 与重采样（如 SMOTE / 随机欠采样）；对比有无特征缩放（标准 / 鲁棒）。每项都记录验证 + 测试指标，不能只看其一。

## 硬性约束

- 不通过反复查看测试集结果来选参数或阈值；测试集只能最终评一次。
- 二分类定义与标签语义保持不变（攻击=正类，`label==1`）。
- 如需新增 CLI 子命令或脚本，放在 `ml/` 下，风格沿用 `ml/cli.py`；同时补 `tests/` 下的回归测试，先跑通现有 `pytest`。
- 产物写 `artifacts/`（已被 `.gitignore`，不入库）；不要把原始/处理后的数据或模型二进制提交进来。

## 产出与验收

在 `docs/experiment-quality.md`（由你新建）输出一份报告，必须包含：

1. 去重敏感性对比表（A/B/C 三组 × 六项指标 × 训练样本数/去重条数）。
2. 一段明确结论：重复记录对验证、测试指标分别造成多大影响，是否值得训练前去重。
3. 一次“仅验证集选参 + 选阈值”的完整记录：搜索空间、选择依据、最终阈值、最终测试集指标，并和基线 16.07% 测试 FPR 对比。
4. 每个数字可复现：注明命令、seed、随机性来源、运行环境（可参照 `artifacts/baseline/summary.json` 的 environment 字段）。

判定“完成”的标准：报告数字可由他人用仓库内命令 + 固定 seed 复现，且结论不依赖测试集调参。
