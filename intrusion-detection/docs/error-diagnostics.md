# 误报、漏报、阈值实验与重复数据分析

2026-09-15。入口：评估分析 `/evaluation`，保留原测试集评估图表，新增误差诊断与历史去重对比。

## 使用

1. 默认显示基础模型验证集，点击“误报正常样本”或“漏报攻击样本”切换明细。
2. 拖动0至1的阈值滑块，步长0.01；五项指标和误报/漏报数量直接在浏览器更新，无需重新训练。明细延迟250毫秒查询，过时响应不会覆盖最新阈值。
3. 明细按原数据行升序分页，每页20条。CSV物理行号=原数据行号+2（含表头）；完整特征包含原id、42个输入特征及原标签，可定位原始记录。
4. 测试集切换项仅查看固定阈值0.5的误差记录，API同样拒绝其他测试阈值。页面试验不改模型包、检测阈值或最终测试成绩。
5. 去重区域展示任务02已完成的A/B/C指标及结论；与滑块使用的基础模型验证试验分别标注，不混用。

## 数据准备

已有基础模型、原始数据与 `data/processed/test_predictions.csv` 时运行：

```powershell
.\.venv\Scripts\python.exe -m ml.error_analysis
```

命令不训练模型。按基础模型记录的特征分组协议重建验证划分，对验证行推理；测试样本直接使用原有固定预测，二分类攻击分数由预测类别分数还原。重新计算固定分类指标用于一致性校验，不重新选择测试阈值。浮点还原可能改变极少数并列分数的AP排序，因此测试AP仍使用原报告。

产物在 `artifacts/baseline/diagnostics/`，包括两份带原行号/标签/特征/攻击分数的CSV、101个验证阈值的统计以及源文件摘要。源数据、模型、预测和产物摘要不匹配时返回中文409，缺少数据返回中文404。CSV及模型不入Git。

去重对比直接读取 `artifacts/quality-02/` 的冻结结果；缺失时显示独立提示，不影响阈值和样本功能。历史实验的指标、局限及复现步骤见 `docs/experiment-quality.md`。

## 新增接口

|GET路径|说明|
|---|---|
|/api/evaluation/diagnostics|验证阈值网格、固定测试统计、模型摘要|
|/api/evaluation/errors|split=validation或test；kind=fp或fn；threshold步长0.01；page和page_size（最多100）|
|/api/evaluation/duplicates|冻结去重对比表、重复/冲突数量、结论和历史选参结果|

errors返回total、items、split、threshold、source_file。items包含真实类别、预测类别、攻击分数与原始记录。分块读取后只保留所需页。所有前端请求包含加载、错误重试及零错误样本空态；页面卸载停止定时器，切换阈值清空旧明细。

## 实际网页验收

在验证集35,196条上，阈值0.50→0.70：

|指标|0.50|0.70|
|---|---:|---:|
|误报正常样本|549|194|
|漏报攻击样本|1,301|2,456|
|正常误报率|4.94%|1.74%|
|攻击召回率|94.60%|89.80%|
|攻击F1|96.10%|94.22%|

网页已验证切换误报/漏报和打开完整特征。例如验证原数据行48017的真实类别为攻击（Fuzzers），攻击分数约0.642643，在0.70阈值下属于漏报。滑块置0时漏报为0，提供空态。测试范围切换后阈值固定0.5，统计误报5,945条、漏报1,466条。

去重结论：移除74,301条训练源重复记录，存在229组标签冲突；在原测试集保持不变时，固定阈值去重模型误报率从16.07%增至30.38%。本次不建议直接采用keep=first去重替换基线；非重叠测试子集只作诊断，不是最终成绩或泛化上界。

自动验证：57项测试通过；前端生产构建通过。新增测试覆盖阈值边界与相等分数、FP/FN原行号、分页、测试阈值锁定、步长验证、缺失和过期数据。
