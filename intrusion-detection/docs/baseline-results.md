# 基础实验记录

记录日期：2026-09-13。下列数据来自本机真实运行 `python -m ml.cli baseline`，不是预设目标。

## 数据与处理

- UNSW-NB15 公开镜像：原训练文件175,341条，原测试文件82,332条，各45列。
- 删除id、label、attack_cat后使用42个特征，其中39个数值和3个类别特征。
- 根据特征行哈希分组划分原训练文件，训练140,145条、验证35,196条。
- 训练/验证没有相同特征组重叠。所有预处理仅在训练部分拟合。
- 原训练文件中有74,301条重复特征记录。原测试文件有8,541条特征记录也出现在原训练文件中，因此不能将此指标描述为完全无重复的独立泛化评价。
- 保留原测试文件，不按测试效果选参数或阈值。后续论文应另做预先定义的去重敏感性分析。
- 来源、固定镜像提交及SHA256见configs/dataset_source.json。官方入口暂不可用，未与官方原文件逐字节比对。

## 模型

RandomForestClassifier，n_estimators=80，max_depth=18，min_samples_leaf=2，class_weight=balanced，random_state=42，n_jobs=2。二分类阈值固定0.5，以攻击为正类。模型及预处理共用同一管道。

训练耗时32.663秒。当前为一次运行记录，不是多次测量的稳定性能承诺。环境为Windows 11、Python 3.12；软件版本见requirements-lock.txt，处理器记录见artifacts/baseline/summary.json。推理计时包含预处理和预测概率，不包含CSV读取与结果落盘。

测试结果显示召回率较高，但正常样本误报率约16.07%，后续应在训练/验证协议内改进并重新评价，不能宣称已适合真实网络部署。

100条示例输入输出40条“正常”、60条“攻击”；完整测试文件输出32,521条“正常”、49,811条“攻击”。这些是预测类别数量，不是真值数量。
