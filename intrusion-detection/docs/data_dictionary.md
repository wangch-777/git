# 数据字典（占位）

> 本文档用于记录字段含义、类型与处理方式。正式内容必须基于实际下载的
> UNSW-NB15 文件表头与类别计数核验后补全，不能照抄数据集介绍。

## UNSW-NB15 主要字段

| 字段 | 类型 | 含义 | 处理 |
|---|---|---|---|
| id | 标识 | 记录序号 | 排除，不入特征 |
| dur | 数值 | 连接持续时间 | 数值特征 |
| proto | 类别 | 传输层协议 | OneHot 编码 |
| service | 类别 | 服务类型 | OneHot 编码 |
| state | 类别 | 连接状态 | OneHot 编码 |
| sbytes / dbytes | 数值 | 源/目的字节数 | 数值特征 |
| spkts / dpkts | 数值 | 源/目的包数 | 数值特征 |
| label | 目标 | 二分类标签（0/1） | 监督目标 |
| attack_cat | 目标 | 攻击类别名 | 多分类监督目标 |

## 泄漏控制

- `label`、`attack_cat`、`id` 一律排除在特征矩阵之外。
- 预处理参数仅在训练子集拟合，验证/测试只 `transform`。
- 官方测试集保持隔离，不参与任何调参。
