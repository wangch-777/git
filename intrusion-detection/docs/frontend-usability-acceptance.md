## 验收项与结果

### 1. 从首页完成一次完整操作
- 首页「快速开始」四步卡片文案与顺序正确：导入数据 / 训练模型 / 批量检测 / 查看结果。
- 点击「查看结果」自动跳到最近成功检测任务详情（实测路由 `/detections/4`）。
- 详情页正常渲染预测结果表格（数据行序号、预测结果、预测类别分数），统计文字显示「当前筛选：100 条，正常 34 条，攻击 66 条，预测攻击占比 66.00%」，并提供「下载当前筛选结果 CSV」链接，无报错。
- 侧边栏切换到「模型实验」正常，无白屏。

### 2. 三类指标来源明确分离（不混为一谈）
- 「基础模型测试指标」→ 标注「来源：测试集（UNSW-NB15 原划分）」，展示测试集召回率/误报率/F1/样本数。
- 「最近训练实验（验证指标）」→ 标注「来源：训练时留出的验证集」，列名写明「验证指标（准确率/攻击召回率/F1/误报率）」。
- 「最近检测任务（预测数量）」→ 标注「来源：检测预测统计，非真实标签，不含准确率」，只显示预测行数。

### 3. 状态区分：加载 / 空 / 失败，错误可重试
- 三个分区分别维护自己的 `loading / error / 空数据` 状态，互不影响。
- 请求失败显示错误告警 + 「重试」按钮；空数据显示引导 + 跳转按钮；加载中显示 loading。
- 修复断网误报：此前 `/api/baseline` 请求失败会同时显示「尚未训练基础模型」空状态；现将「请求失败」与「尚未训练」分离——空状态仅在请求成功且 `ready=false` 时出现，断网时只显示错误与重试，不再误报「尚未训练」。
- `Detections`、`DataManagement` 同样把「接口失败（重试）」与「前置数据缺失（引导）」分开。

### 4. 响应式（窄窗口）
- 实测约 490px 宽度：快速开始四卡片纵向堆叠、指标卡由 4 列收为单列、三个分区可正常查看，无横向溢出截断。
- 表格使用 Element Plus 自身横向滚动能力，窄窗口下仍可操作。
