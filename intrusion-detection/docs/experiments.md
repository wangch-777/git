# 模型实验使用与验收

## 已实现能力

网页路径：`/experiments`。原数据库已有实验表，但实验接口是501占位；本次扩展原表并补齐管理接口、后台训练和页面。

- 逻辑回归：正则化强度倒数、最大迭代次数。
- 决策树：最大深度、叶节点最少样本数。
- 随机森林：上述树参数及树数。
- 通用参数：类别权重、随机种子、验证分组占比。
- 创建、列表、详情、重命名、删除、失败或中断重试。
- 保存数据摘要、特征协议、参数、划分、样本数、训练耗时、指标、状态和时间。
- 成功模型自动注册至批量检测；同组实验按F1降序展示，误报率用于同分排序。

## 运行与恢复

沿用启动脚本中的单Worker，检测与训练共用队列，优先处理较早创建的任务。数据库持久化排队状态；重启后排队任务继续执行，遗留训练中任务标为“已中断”，用户点击重试创建新实验，从头训练并保留旧记录。这里不提供模型拟合过程中的断点续训。

进度表示读取、划分、拟合、验证、保存等阶段，不是树数或迭代次数。小样本通常不到一秒即可训练完成，轮询可能直接显示100%，日志仍保留全部阶段。页面每两秒刷新。训练期间页面可切换；长任务会占用此单Worker，后续检测需要排队。

旧SQLite首次启动时在数据库旁保存 `*-before-experiments.sqlite3` 备份，再补齐新增字段；重复启动不会重复迁移。删除为软删除，同时停用模型；不删除历史检测或模型文件。运行中实验不可删除。

## 数据与指标规则

“准备训练示例”核验原训练文件SHA256，固定种子42按标签抽取2000条；不使用原测试文件。也支持上传符合现有特征协议且包含0/1真实label的CSV。至少20条，两类各不少于5条。

相同特征记录通过分组划分放在同一侧，预处理只在训练侧拟合。20%指分组占比，样本占比可能不同。若某侧缺少类别则以中文报错。固定阈值0.5；不使用label、attack_cat、id作为预测特征。

对比组由数据摘要、特征协议、种子、验证比例和划分版本共同确定。不同组不混排。准确率、攻击召回率、攻击F1越高越好；正常误报率为FP/(FP+TN)，越低越好。这些是验证指标，不能代替独立测试结果，也不能单凭一次示例得出算法优劣的普遍结论。

每次实验产物在 `artifacts/experiments/实验编号/`：模型包及元数据、`metrics.json`、记录原CSV行索引的 `split.json`。运行产物由Git忽略，不随源代码提交。

## API

接口前缀 `/api`，错误响应的detail为中文。

|方法|路径|用途|
|---|---|---|
|POST|/experiments/sample|准备带标签示例|
|POST|/experiments|保存配置并排队，返回201|
|GET|/experiments|实验列表|
|GET|/experiments/{id}|状态、日志、指标及追溯信息|
|PATCH|/experiments/{id}|修改名称；训练参数不可覆盖|
|DELETE|/experiments/{id}|软删除并停用模型|
|POST|/experiments/{id}/retry|失败或中断后创建新实验|
|GET|/models|包括成功实验产物的可用模型列表|
