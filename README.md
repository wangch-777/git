# Security research projects

## Multilingual indirect prompt-injection benchmark

[项目说明与运行步骤 / Project and quick start](prompt-injection-bench/README.md)

A Python evaluation pilot for Chinese, English and mixed-language instructions embedded in external documents. Includes paired clean controls, three defense settings, frozen experiment configurations, Ollama integration, automated scoring and human-review exports.

**Current scope:** synthetic pilot data and reproducible tooling. Mock demonstrations are not research findings.
